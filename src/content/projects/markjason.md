markjason is a native macOS editor for people who work across Markdown, JSON, and AI-generated content. It combines a focused writing surface with structured-data workflows, so builders can draft prose, inspect JSON, validate content, and move between formats without bouncing between separate tools.

The app was built solo with AI-assisted coding and ships as a polished Mac app, with a public website, downloadable releases, and an open GitHub repository.
