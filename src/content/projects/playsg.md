PlaySG started with a question that comes up when planning a day out with kids. Is there a playground near where we’re already going, and will it work if it’s hot or raining? The map uses OpenStreetMap for playground locations and OneMap for postal code search. Families can look for neighbourhood playgrounds, free indoor play areas, and water play.

One data problem surfaced when a user spotted playground pins that pointed to new housing estates still under construction. Some playgrounds had been mapped from site plans before they were built. Codex and Claude helped build and review changes to the map, and the pin review recorded evidence for each decision. Where the available evidence couldn’t confirm a playground, the review left it marked as uncertain.
